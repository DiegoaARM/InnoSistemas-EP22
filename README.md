# InnoSistemas-EP22

InnoSistemas es una aplicación hecha para FabricaEscuela en el semestre 2025-1, y consta de un software encargado de la gestión de cursos, materias y equipos para la entrega de actividades. La aplicación permite a los estudiantes inscribir equipos asociados a una materia para realizar las entregas de las tareas asignadas por los profesores, incluido un método de búsqueda de equipo de acuerdo a las habilidades de cada persona y sus roles. Además, permite a los profesores calificar las tareas y mandar recomendaciones y notas.

InnoSistemas está hecha con Java y SpringBoot, mediante el uso de GraphQL para las peticiones. Además, consta de métricas hechas con grafana y prometheus, y todo esta subido con docker y orquestado con docker-compose.
